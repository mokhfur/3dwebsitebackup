# Shafi Chowdhury — personal showcase

A single-page, 3D-animated personal website for Shafi Chowdhury, Founder & Managing Director of Shafi Consultancy Ltd.

Everything lives in `index.html`. It loads Tailwind CSS, Three.js r128 and Lucide icons from public CDNs and needs no build step: open the file in a browser or host it on any static host (GitHub Pages, Netlify, Hostinger).

## Sections
- Hero with an interactive 3D particle network
- Interactive 3D models: SDTM/ADaM traceability helix and a layered PopPK concentration surface
- Clinical analytics dashboard: Kaplan–Meier survival and multi-dose response charts
- TLF reporting engine: Table 14.1, Listing 16.2, Figure 14.3 with a mock PDF export
- NONMEM analysis hub: control stream, simulated run and observed-vs-predicted plot

All charts, tables, listings and model outputs use simulated data and do not represent any real study, sponsor or patient.

## Publishing with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
